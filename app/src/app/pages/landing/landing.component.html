Develop UI

Sistema de documentación para construir interfaces coherentes y unificadas
con Angular Material y PrimeNG.

Implementar más rápido

Todo lo que necesitas para construir componentes SINTRA en un solo lugar.

Sistema de desarrollo de interfaces que unifica estilos, componentes y bloques de maquetación. Permite que Angular Material y PrimeNG compartan la misma apariencia y que toda la aplicación mantenga una estructura coherente.

No es un una librería nueva.

Es una referencia técnica para construir interfaces de forma consistente sin tener que consultar en otras documentaciones sobre estilos o bloques de desarrollo.

¿Qué incluye?

Estas son las secciones de las que consta esta apllicación

chrome_reader_mode

Components

Componentes documentados con ejemplos reales, API clara y criterios de uso definidos.

Blocks

Bloques de interfaz reutilizables basados en patrones reales de aplicaciones.

Wiki

Normas de diseño, decisiones técnicas y criterios que rigen el sistema.

¿Cómo se utiliza?

Explora un componente, revisa sus ejemplos, consulta la API y replica el patrón en tu aplicación.

La documentación está pensada para usarse mientras desarrollas, no para leerse de principio a fin.
